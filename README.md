# onshape-bolt1
A hex bolt with modeled threads. It was made in Onshape as my first CAD project.

## About:
For this project I wanted to become comfortable using the fundamental tools in CAD. I researched thread depth, pitch and used the standar recommended values for size and pitch. Then I modelled the bolt to practise sketching, extruding, revolving, sweep & helix.

## Specifications/dimensions:
- Thread: 1/4" -28 (UNF), 28 threads per inch, with 1/28" pitch
- Major diameter: 0.25 inches
- Shaft length: 1 inch
- Overall length: 1.188 inches, head height being 0.188 inches
- Head: hexagonal in shape, 0.5 inches between opposite sides, 0.2887 inches per side
- Thread profile: sharp 60 degree angle, roughly 0.03 inches depth \
\
The thread sizes and pitch follow the standard values I found from the sources below however the head dimensions deviate slightly and are larger than standard 1/4" bolt head (they are 7/16 across flats).

## Sources:
- UNC/UNF thread chart (https://www.echosupply.com/blog/unified-national-thread-chart/) : Gave me information on thread size, pitch, and major/minor diameters for 1/4" -28 UNF
- Onshape Bolt Tutorial (https://www.youtube.com/watch?v=HkEdzw7441Y) : To help discover which order to work in and give extra guidance on different onshape tools + dimensions to begin with
- Onshape Bolt Tutorial 2 (https://www.youtube.com/watch?v=Qu-OZO6xURM) : To explore differences between different models and different sizes of bolts

## What I learned:
- How to build the bolt using extrudes and revolves
- How the thread depth and pitch relate to each other
- Fully constraining my sketches

## What I would do differently:
- I would use a truncated 60 degree profile to match the standard thread depth, as when completing this model I simplified the bolt slightly. I would use a flat crest and root as mine is quite sharp.
- I would like to try onshape's built in thread tools to use some of the standard sizes
- Model a nut to match the bolt, and assemble them.
